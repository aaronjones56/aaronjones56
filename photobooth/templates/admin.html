    Imprimante

    Canon SELPHY CP1500

    • Installez le pilote Canon puis vérifiez que l'imprimante apparaît dans Paramètres › Bluetooth et appareils › Imprimantes.
    • Dans les Préférences d'impression : papier Carte postale (100 x 148 mm), orientation Portrait, sans bordure.
    • Le format 1200 x 1800 pixels correspond exactement à un tirage 10 x 15 cm à 300 dpi.
    • Une page de test permet de vérifier le cadrage : le cadre rose doit être visible sur les quatre bords.

    Cadres

    Ajouter un cadre

    1. Créez un dossier dans static/frames/ (lettres, chiffres, tirets), par exemple static/frames/festicoat/.
    2. Ajoutez frame.png : 1200 x 1800 pixels, zones transparentes là où la photo doit apparaître.
    3. Facultatif : preview.jpg (vignette, sinon générée) et config.json (nom, ordre, emplacements des photos, QR code).
    4. Cliquez sur « Recharger les cadres » : le nouveau cadre est proposé immédiatement sur la borne.
